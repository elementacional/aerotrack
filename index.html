Arquitetura do sistema

Resumo técnico · Documento completo disponível no repositório

Stack recomendada (leve)

  • Frontend: HTML + CSS + JS (este arquivo) ou Vite + React
  • Backend: Python FastAPI (async)
  • Banco: PostgreSQL + Redis (cache e filas)
  • API de voos: Duffel (principal em 2026)
  • Workers: RQ / Celery para alertas em background

Por que roda bem no GitHub

  • Este demo é 100% estático → GitHub Pages em 1 clique
  • Sem build, sem Node, sem Docker obrigatório para a demo
  • Backend real (FastAPI) pode viver em outro serviço (Railway, Fly.io, Render) e o frontend continua no Pages
  • Arquivo de arquitetura completo: arquitetura-app-rastreamento-passagens.html

Como publicar no GitHub Pages

  1. Crie um repositório (ex.: aerotrack)
  2. Suba este index.html na raiz (e o HTML de arquitetura se quiser)
  3. Settings → Pages → Source: Deploy from a branch → branch main / root
  4. Aguarde ~1 minuto → URL: https://SEU-USER.github.io/aerotrack/
